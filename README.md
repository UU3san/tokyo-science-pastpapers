# 都立入試 理科過去問（資料入り）

2014〜2024年度の問題画像131ページ・公式正答表11ページを収録しています。65大問をすぐに選択して印刷できます。

## 使い方

1. 年度と単元を選びます。「全年度」で年度をまたいで検索できます。
2. 必要な大問にチェックします。「問題を見る」で元の図表を確認できます。
3. 「選んだ問題をA4印刷」を押します。A4用紙・倍率100%・ブラウザのヘッダーとフッターをオフにして印刷してください。PDFとして保存することもできます。
4. 「正答を印刷」では、選択した年度の公式正答表全体が各年度1回ずつ出力されます。

共通の実験文や図表を含めるため、初期索引は大問単位（原本2ページずつ）です。大問1・2は複数単元を含むため「小問集合・総合」に分類しています。小問単位に分ける場合は「資料を追加・問題の範囲を調整」から必要な範囲を追加登録できます。単元の編集もできます。

## GitHub Pagesへの配置

前回版を使っている場合も、今回のZIP内のファイルで置き換えてください。assets フォルダーと catalog.json が必要です。

1. ZIPを解凍します。
2. GitHubの専用リポジトリのルートに、index.html、app.js、catalog.json、assetsフォルダーなど、解凍した内容を配置します。
3. ファイル数が多いため、GitHub Desktopでリポジトリを開き、解凍した内容をコピーしてコミット・Pushするとまとめて追加できます。ブラウザから追加する場合はファイルを分けてアップロードしてください。
4. Settings → Pages → Deploy from a branch で main と / (root) を指定し、保存します。
5. Pagesに表示されたURLをChromeまたはEdgeで開きます。

index.htmlのダブルクリックでは起動できません。手元で試す場合、Pythonがあれば展開フォルダーで `py -m http.server 8000` を実行し、http://localhost:8000 を開きます。

## 保存について

収録済み画像と索引はアプリのファイルに含まれるので、同じGitHub Pagesを開いた別のPCでも利用できます。追加したPDF、独自の問題範囲、単元の編集は使用中のブラウザに保存されます。別PCには自動で共有されず、ブラウザのサイトデータを削除すると独自登録が消えます。

収録画像の表示・印刷には外部ライブラリの読み込みは不要です。追加PDFの表示ではPDF.jsをCDNから取得するためインターネット接続が必要です。
